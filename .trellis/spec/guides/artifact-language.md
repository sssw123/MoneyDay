# 研发产物语言规范

> **契约/规定**：所有 Trellis 任务相关的核心规划文件必须使用**中文**编写。

---

## 适用范围

本规定强制适用于在 `trellis` 工作流中生成或维护的所有任务相关文档（无论是由 AI 自动生成，还是由开发者手动编写），重点包括以下三类文件：

1. **`prd.md`**：需求描述、验收标准与约束条件。
2. **`design.md`**：技术设计、边界范围与权衡决策。
3. **`implement.md`**：执行计划、步骤拆解与验证命令。

除此之外，存放于 `research/` 目录下的调研记录，以及任务目录下的其他产物也强烈建议采用中文，以保证整个研发上下文的交流与阅读一致性。

## 执行原则

1. **统一沟通语境**：在 AI 与人类开发者的多轮交互、审阅和确认环节中，中文能够更精准、快速地传达业务意图与系统架构设计。
2. **术语准确性**：遇到特定的英文技术专有名词（如 API 接口名、类名、库名、架构名词等）可以保持英文，不强求生硬翻译，但在描述业务逻辑和执行步骤时，行文必须为中文。
3. **AI 生成约束**：任何 Trellis 的 Agent（如 `trellis-brainstorm`、`trellis-implement` 等）在产出、更新上述文档时，都必须以此为契约，直接输出中文格式的规划文件。
