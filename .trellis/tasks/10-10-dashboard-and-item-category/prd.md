# PRD: 看板周期透视与固定项目分类

## 目标与价值
1. **首页看板周期情况透视**：
   - 维持「总资产 = 所有账户余额之和」。
   - 新增周期财务卡片透视：展示「固存」、「本期结余/超支（红绿区分）」以及「最终结余 = 固存 + 本期结余/超支」。
   - 目标资金呈现：明确总资产中预留给目标的扣减关系，且体现目标进度来源于周期结余。
2. **固定项目标签分类关联**：
   - 在模板配置与标签编辑时，支持为固定项目（固收/固支）选择具体的一级分类（Category）。
   - 一键到账/支付时，生成的交易自动写入该 `categoryId`，使这笔流水能被统计进首页的分类支出/收入图表中。

## 详细功能需求

### 1. 首页看板升级 (Dashboard.vue & StatDTO)
- **总资产**：依然取所有账户可用资金总和。
- **本周期财务状况卡片**：
  - **固存总额**：展示本期必须存下的钱（如 ¥4,000）。
  - **本期结余/超支**：展示 `总收入 - 总支出 - 固存`。
    - 若结余 >= 0：绿色粗体显示「本期结余: +¥X」。
    - 若结余 < 0：红色粗体显示「本期超支: -¥X」。
  - **最终净沉淀结余**：`最终结余 = 固存 + 本期结余`（即当期净存下的总现金）。如果大于 0 绿色，小于 0 红色。
- **历史周期趋势或表格查看**：
  - 在看板中支持切换或直观查看各周期明细数据（固存、结余、最终结余）。

### 2. 固定项目标签绑定分类 (Settings.vue & FixedItem)
- **数据结构扩展**：`FixedItem` 实体新增 `categoryId` (Long) 和 `categoryName` (String)。
- **界面交互**：
  - 在模板编辑弹窗（`Settings.vue`）中，添加/编辑标签时：
    - 类型为「固收」：下拉筛选展示所有的收入分类。
    - 类型为「固支」：下拉筛选展示所有的支出分类。
    - 类型为「固存」：无需强制分类（或可选）。
- **记账打通**：
  - 点击周期标签「到账/支付」时，调用接口将该标签所配置的 `categoryId` 写入生成的真实 `Transaction`。
  - 记账后，首页「本周期分类支出占比」饼图自动计入该笔开销。

## 验收标准
- [ ] 模板编辑页中，固定项目可以下拉选择分类。
- [ ] 周期表点击固支（如房租）支付后，记账明细中能看到对应的分类，且首页分类饼图中有该分类的数据。
- [ ] 首页看板卡片清晰拆解：固存、本期结余/超支（红绿分明）、最终结余（固存+结余）。
- [ ] 目标与资产关系呈现直观明确。
