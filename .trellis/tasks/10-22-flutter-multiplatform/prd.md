# Flutter 六端重构

## 目标
统一 Web、Android、iOS、Windows、macOS、Linux；完整迁移两套前端；Material 3；并行开发，验收后切换。

## 已确认决策
- 用户已审阅并明确要求实施完整六端方案。
- Material 3 全新界面；旧版保留到六端验收通过。
- Spring Boot 是唯一账本和业务规则来源；不增加离线账本、同步或客户端扣款。
- Web 会话级存储，原生内存会话；重启后登录。

## 验收标准
- 本任务覆盖的旧版功能无缺失，使用现有 API 和中文业务术语。
- 类型检查、相关单元及 Widget 测试通过。
- 401/403、强制改密、用户切换旧响应隔离、财务写入不自动重放通过。
- 六端构建及运行验收逐项记录；缺少主机、SDK、签名或后端时标记待验收，不降低标准。

## 范围外
商店发布、生产部署、旧版源码删除、SQLite 迁移、服务端账务规则重写。
