# PRD: 固收/固存/固支标签化与一键记账

## 目标与价值
将原本固化在周期模板上的单一「固存」「固收」字段，解耦为可灵活添加、删除、修改的**明细标签数组**（例如“房租”、“工资”），并增加「固支」类型。这些标签直接随模板生成快照。
在周期视图中，针对「固收」和「固支」标签，用户可以点击“到账/支付”一键生成真实流水，省去每个月重复记固定账单的麻烦。

## 需求说明

### 1. 模板标签化管理 (Settings)
- 用户在编辑/新增周期模板时，可以管理该模板的「固定项目标签」。
- 每个标签包含：
  - **名称** (如 "房租")
  - **类型**：固收 (Income)、固支 (Expense)、固存 (Deposit)
  - **金额**
- 这些标签作为一个整体（JSON）保存在模板中，取代原有的 `defaultFixedDeposit` 和 `defaultFixedIncome`。

### 2. 周期快照继承
- 当创建新周期快照时，系统将模板上的标签数组完整复制到快照中。
- 为「固收」和「固支」标签初始化 `isBooked: false` 状态。

### 3. 一键记账体验 (周期表)
- **展示**：周期表每行可以展示该周期内的所有标签。
- **固存逻辑**：固存标签只作记账因子的展示，从周期结余中扣除，**不产生**交易记录，没有操作按钮。
- **固收/固支逻辑**：带有“到账”或“支付”按钮。
  - 点击弹出二次确认（选账户、确认日期、可调金额）。
  - 确认后：**生成真实的 Transaction（分别对应收入和支出）**，并更新快照中对应标签的 `isBooked` 为 true，按钮变灰。
- **结余计算**：`周期结余 = 真实总收入(含已到账固收) - 真实总支出(含已支付固支) - 固存标签总和`。

### 4. 模板变更同步
- 在设置中修改某个模板的标签时，系统自动更新所有 `cycle_end_date >= 今天`（当前及未来）周期的快照标签（只覆盖未 booked 的条目，或者整体替换并保留已有 booked 状态，详见技术设计）。历史快照完全不受影响。

## 验收标准
- [ ] 模板支持动态增删改三种类型的标签。
- [ ] 废弃原有的单体固定字段，改用 JSON 数组。
- [ ] 周期列表能显示快照下来的标签明细。
- [ ] 固收和固支标签可以点击支付/到账，生成交易并更新为已完成。
- [ ] 固存标签自动从本周期结余中扣减。
- [ ] 修改模板后，当前周期未完成的标签会相应改变。

## 非需求 (Out of Scope)
- 标签不支持绑定分类（Category），生成的交易目前不归属于特定的报表分类（或在备注中标注）。
