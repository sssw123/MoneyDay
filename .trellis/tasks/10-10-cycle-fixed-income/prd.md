# PRD: 新增周期固收功能

## 背景

用户每个账单周期有固定收入（如薪资），希望系统能记住这个金额，减少重复手动输入，同时保留每次确认时调整实际金额的灵活性。

## 需求描述

### 核心功能

1. **全局默认固收配置**：在设置页新增"默认固收"输入框（单独一行），存储于 `CycleTemplate.defaultFixedIncome`。
2. **周期快照继承**：每个 `CycleRecord` 在首次创建时，从默认模板快照继承 `fixedIncome` 金额。
3. **模板变更传播**：修改 `CycleTemplate.defaultFixedIncome` 时，自动同步更新所有 `cycle_end_date >= 今天` 的快照（当前及未来周期），历史快照不变。
4. **到账操作**：周期表每行显示「到账」按钮。
   - 点击弹出对话框：预填当前周期固收金额（可修改）+ 选择入账账户 + 日期（当前周期默认今天，历史周期默认周期首日）
   - 确认后：生成真实收入 Transaction（type=1）+ 更新快照 `fixedIncome` 为实际金额 + 标记 `isFixedIncomeBooked = true`
5. **已到账状态**：`isFixedIncomeBooked = true` 时按钮变灰禁用，防止重复记录。
6. **历史补记**：历史周期「到账」按钮正常可用，日期默认为该周期首日。

### 不在范围内

- 周期表不新增「固收」列，到账后体现在现有收入列
- 不自动生成收入交易，必须用户手动触发「到账」

## 验收标准

- [ ] 设置页可配置、保存默认固收金额
- [ ] 新周期快照自动继承默认固收
- [ ] 修改模板固收后当前及未来周期显示更新，历史不变
- [ ] 周期表「到账」按钮：未到账可用，已到账变灰
- [ ] 到账弹窗金额可改、可选账户、可改日期
- [ ] 确认后收入出现在当期周期收入列
- [ ] 历史周期可补记
