# 移动端前端项目构建与触屏适配 (android-frontend)

## Goal

在项目根目录下独立创建 `android-frontend` 移动端前端工程，采用 **Vue 3 + Vite + TypeScript + Vant 4** 现代移动端技术栈，打造专属于手机触屏原生手感的交互体系，完整移植并适配 PC 端 MoneyDay 的核心功能模块；并预留清晰的 API/Storage 抽象适配器，为未来无缝集成 Capacitor 打包 APK 及纯手机本地存储奠定坚实基础。

---

## Background & Confirmed Facts

1. **多端诉求**：当前系统为 PC 桌面端布局（Ant Design Vue 大表格与弹窗），在手机竖屏与触屏下操作极其不便，需独立构建移动端专属前端；
2. **两阶段演进契约**：
   - **第一阶段（当前 In-Scope）**：建设 `android-frontend` 工程，全面采用 Vant 4 移动端 UI 库，通过 Axios 连接当前 Spring Boot 后端，实现全功能触屏操作闭环；
   - **第二阶段（未来演进）**：通过 Capacitor 生成 Android 原生工程，打包独立 `.apk`，并将数据请求层切换为手机本地 SQLite 离线运行。
3. **交互规范契约**：
   - 采用标准移动端底部导航栏（Tabbar）作为主路由骨架；
   - 告别复杂桌面表格，改为触屏友好的卡片流（Card List）、滑动单元格（SwipeCell）与折叠面板；
   - 弹出层采用原生移动端手感的底部动作面板（ActionSheet）、弹出层（Popup）和滚轮时间选择器（DatePicker）。

## Requirements

### 1. 工程搭建与基础架构
- 在根目录新建 `android-frontend` 独立项目（Vue 3 + Vite + TypeScript）；
- 引入最新版 **Vant 4** 移动端组件库及样式；
- 配置移动端视口（Viewport）与轻量移动端样式重置；
- 封装 `utils/request.ts`，支持局域网 IP / 环境变量动态配置后端服务地址。

### 2. 移动端路由与导航架构
- 底部常驻 **Vant Tabbar** 导航：
  1. **首页看板 (`/`)**：四重资产卡片、周期结余池、近期透支与收支环形概览；
  2. **记账明细 (`/transactions`)**：按日期分组的流水列表，悬浮快捷记账按钮（FAB）；
  3. **周期预算 (`/budget`)**：周期固定收支卡片、一键到账/扣款确认；
  4. **未来计划 (`/plan`)**：顶部分段器（Tab）整合【目标】、【心愿单】、【透支负债】；
  5. **我的/设置 (`/mine`)**：待办中心入口（带红点角标）、账户管理、分类管理、周期模板设置。

### 3. 核心功能移动端交互适配
- **快捷记账**：底部弹出层（Popup），大字号数字键盘、分类快捷图标网格选择、账户与日期滑动选择；
- **分期负债管理**：卡片展示还款进度条、待还期数、下期还款日，支持一键还款/结清；
- **心愿单与目标**：进度环/进度条直观展示，一键兑现心愿；
- **待办中心**：移动端消息列表，支持一键补扣分期（底部弹窗切换账户）、周期账单核对、心愿达成兑现。

---

## Out of Scope

1. 本阶段暂不直接打包 `.apk`（预留 Capacitor 配置文件与目录结构，留待下一阶段）；
2. 本阶段仍调用后端 API，不直接接入手机本地 SQLite 数据库。

- [ ] 底部 Tabbar 流畅切换 5 大核心模块；
- [ ] 可以在手机上完成完整的记账、查看资产、周期固收支确认、分期还款、心愿兑现等核心闭环；
- [ ] 待办中心红点与待办列表在手机端正常联动处理。
